# OIKOS Genomics Bioinformatics Reports

This repository contains technical reports and supporting figures produced by the OIKOS Genomics Bioinformatics Team. Its primary purpose is to share project results with collaborators in a clear, accessible, and centralized format. The reports document project context, analytical methods, quality-control procedures, results, and the current status of bioinformatics analyses.

## Available reports

| Project | Report | Description | Last updated |
|---|---|---|---|
| KAUST Red Sea genomes | [KAUST_genomes.md](KAUST_genomes.md) | Genome assembly and annotation of 23 Red Sea and Arabian marine species using Oxford Nanopore Technologies long reads | 10 September 2026 |

## Repository structure

- `README.md`: overview and index of the reports available in this repository.
- `KAUST_genomes.md`: technical report for the KAUST Red Sea genome project.
- `Figures/KAUST/`: figures and supplementary figures used in the KAUST report.

## Access

This is a public repository. The reports and associated figures can be accessed by anyone with the repository link; no GitHub account is required to view them.

Direct link to the KAUST report: [Genome Assembly and Annotation for Red Sea Species](KAUST_genomes.md)

## Using the reports

Each report is provided as a Markdown document and can be viewed directly on GitHub. Supporting figures are stored in the corresponding project folder and are linked from within each report.

Reports may be updated as analyses progress. When referring to a report, please include the report title, repository URL, and access date. For a reproducible reference to a specific version, use the relevant Git commit.

## Organization

These reports are maintained by the Bioinformatics Team at [OIKOS Genomics](https://oikosgenomics.org/).
